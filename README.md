# 时间里的中国

给孩子做的中国通史 app：**地图为核心**，从夏商周讲到近现代；每个时期里，**天文、历史、地理、文学、文化五个方面放在一起讲**，不是分科；**151 个重大事件**按 21 个朝代排开，点一个事件，地图就亮出它发生的地方。

## 打开方式

双击 `index.html` 即可打开（纯静态网页）；也可以用任意静态服务器打开。页面会从 Google Fonts 加载思源宋体/黑体，离线时自动用系统字体代替。

## 结构

- `index.html`：页面骨架（全宽地图在最上方，地图下方左大事索引、右故事，底部动手练）
- `style.css`：护眼配色（与识字星球字卡页同款底色）
- `data.js`：8 个时期内容数据（每时期 5 个方面 + 引文）
- `mapdata.js`：地图数据（手绘轮廓、现代中国水印轮廓、黄河长江、地点坐标、每时期疆域与路线）
- `dynasties.js`：21 个朝代、151 个重大事件、事件发生地与核心点、类型与转折点、动手练题库
- `map.js`：地图状态与 SVG 渲染（疆域 / 路线 / 都城 / 标记 / 观星点）
- `app.js`：渲染与交互逻辑（时间线、大事索引、连播、搜索筛选、动手练、`#d=朝代&e=事件` 直达）

## 内容（2026-11-06 同步自原型，151 个事件）

- **21 个朝代都有事件**：夏 4、商 4、西周 6、春秋 5、战国 7、秦 7、西汉 8、东汉 7、三国 6、西晋 4、东晋 6、南北朝 6、隋 6、唐 10、北宋 9、南宋 7、元 8、明 9、清 8、近代 13、现代 11，共 151 个，一站一个事件，不再有时期站；每朝代 3 道动手练。
- **21 个转折点**：金边大卡 + 地图金色光圈与星标。
- **事件分 5 种类型**：统一 / 打仗 / 出使 / 建设 / 文化（色点 + 图例）。
- **故事四步**：先走路线 → 发生了什么 → 为什么重要 → 后来怎么样了；下面是这个朝代的五方面。
- **地图上的核心点**：每个发生地旁边一句短话；多地点事件红线按顺序连起来。
- **现代中国水印**：现在的中国疆域轮廓（含台湾、海南）淡蓝虚线印在手绘地图后面，同一坐标系，标“现在的中国”，对照历史发生地与今天地图的关系。
- **地图底部事件描述**：年份 + 标题 + 故事“发生了什么”前 2–3 句，随站点更新。

## 设计

- **地图为核心、占整个宽度**：地图独占最上方一整行；大事索引和故事在地图下方左右两栏；手机端单列（地图上、索引和故事依次在下）。
- **地图随事件变化**：疆域、都城、河道工程、路线、事件点按事件切换；点地图上的标记，讲那个地方在那个年代的故事。
- **换站只就地更新**：点事件、上下站、连播时只换地图框里的图和文字、描述与故事，页面不刷新、不跳动；动手练只在换朝代时重开，同一朝代里换事件，答到一半的题和成绩都留着。
- **大事索引**：常驻，按朝代分组可折叠；每行年份 + 标题 + 类型色点 + 迷你路线；点行就地展开摘要；顶部总数 + 搜索 +“只看有路线的事件”筛选；读过打勾，组头显示“读了 X/Y”（存在浏览器 localStorage，键 `shijian-read-v1`）。
- **连播**：点连播一站停 6 秒，进度条走完到下一站；点任意事件、地点或题目，连播停下来。

## 规矩（与识字星球一致）

- 一页到底，无多级页面跳转；详情内容重要在前。
- 界面不出现原型字眼与内部术语；地图明确标为示意图，不作精确测绘。
- 内容口径：古诗文引文为公有领域原文；年代与史实按通用说法写，传说明确标为传说；不确定的不写。
- 地点坐标按真实经纬度投影核对过：临洮在甘肃定西、秦长城东端是辽东（不是山海关）、隋初洛阳不是东都、赤壁没有成都/建业都城标记、临潼只留在秦灭六国、玄奘站没有成都、唐灭东突厥是阴山战场。
