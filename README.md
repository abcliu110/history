# 时间里的中国

给孩子做的中国通史 app：**时间线为骨架**，从夏商周讲到近现代；每个时期里，**天文、历史、地理、文学、文化五个方面放在一起讲**，不是分科。

## 打开方式

双击 `index.html` 即可打开（纯静态网页，不联网、无外部请求）；也可以用任意静态服务器打开。

## 结构

- `index.html`：页面骨架（时间线列表 → 时期详情）
- `style.css`：护眼配色（与识字星球字卡页同款底色）
- `data.js`：全部内容数据（8 个时期，每时期 5 个方面 + 3 道动手练）
- `app.js`：渲染与答题逻辑（支持 `#era=xxx` 直达某时期）

## 规矩（与识字星球一致）

- 导航只回上一层：详情页返回时间线，不直达首页之外的其他地方；上一时期/下一时期只在同一层级内移动。
- 界面不出现原型字眼与内部术语；详情页重要内容在前（导读 → 历史 → 天文 → 地理 → 文学 → 文化 → 动手练）。
- 内容口径：古诗文引文为公有领域原文；年代与史实按通用说法写，传说明确标为传说；不确定的不写。
