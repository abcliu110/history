# 时间里的中国

给孩子做的中国通史 app：**时间线为骨架**，从夏商周讲到近现代；每个时期里，**天文、历史、地理、文学、文化五个方面放在一起讲**，不是分科。

## 打开方式

双击 `index.html` 即可打开（纯静态网页，不联网、无外部请求）；也可以用任意静态服务器打开。

## 结构

- `index.html`：页面骨架（侧边时间线 + 中央地图 + 故事 + 动手练）
- `style.css`：护眼配色（与识字星球字卡页同款底色）
- `data.js`：时期内容数据（8 个时期，每时期 5 个方面 + 3 道动手练）
- `map.js`：中国示意地图组件（手绘轮廓、黄河、长江、城市点）
- `mapdata.js`：每时期的地图状态（疆域、都城、路线、事件点、观星点）
- `app.js`：渲染与答题逻辑（支持 `#era=xxx` 直达某时期；▶ 播放时间每 3 秒推进一步）

## 设计（v2，2026-11-06）

- **地图为核心**：中国示意地图在每个页面的正中心、最大；时间线与朝代只在旁边显示（侧边栏）。
- 地图随时间变化：疆域、都城、河道工程、路线、事件点按时期切换；点地图上的标记，弹出那个地方的故事。
- 故事围着地图讲：每时期天文、历史、地理、文学、文化 5 个方面放在一起，讲的全是地图上正在发生的事。

## 规矩（与识字星球一致）

- 一页到底，无多级页面跳转；详情内容重要在前（导读 → 历史 → 天文 → 地理 → 文学 → 文化 → 动手练）。
- 界面不出现原型字眼与内部术语；地图明确标为示意图，不作精确测绘。
- 内容口径：古诗文引文为公有领域原文；年代与史实按通用说法写，传说明确标为传说；不确定的不写。
